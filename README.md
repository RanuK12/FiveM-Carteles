# FiveM-Carteles

FiveM resource para gestión de carteles/narcotráfico en servidores RP.

## Estructura del Proyecto

- `fxmanifest.lua` - Manifiesto del resource
- `config.lua` - Configuración principal
- `client/` - Scripts del lado del cliente
- `server/` - Scripts del lado del servidor
- `shared/` - Scripts compartidos
- `locales/` - Archivos de traducción

## Tecnologías

- **Framework**: ESX + QB-Core (configurable)
- **Base de datos**: oxmysql
- **Versión Lua**: Lua 5.4
- **Framework base**: Cerulean

## Instalación

1. Copiar el resource en la carpeta `resources` de tu servidor FiveM
2. Agregar `ensure FiveM-Carteles` en `server.cfg`
3. Configurar en `config.lua`

## Configuración

Editar `config.lua` según las necesidades del servidor.
